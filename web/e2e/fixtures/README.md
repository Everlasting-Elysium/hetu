# E2E fixtures

Binary assets seeded into a throwaway library dir before Playwright runs
(`bin/hetu scan`). Documented here for provenance/licensing.

## Issue #48 (document pager + font)

- `doc-multi.pdf` — a real 3-page PDF, `doc-single.pdf` — a real 1-page PDF.
  Both are generated by a stdlib-only Python script (no external deps); each page
  draws a large "Page N" specimen so `pdftoppm` renders visibly distinct
  thumbnails. Rendering the per-page index requires a PDF renderer on the
  backend's `PATH` (`pdftoppm` from poppler-utils, or `mutool`).
- `specimen.ttf` — **Gruppo** (Regular). Source:
  https://github.com/google/fonts/tree/main/ofl/gruppo — licensed under the
  **SIL Open Font License 1.1**. Used to verify the `kind === "font"` preview +
  "下载字体文件" download entry.

## Issue #62 (image sequence step viewer)

- `seq-frame-01.png` … `seq-frame-04.png` — four solid-color 96×96 PNGs whose
  consecutive numbers make the scanner index them as ONE sequence asset (anchored
  at `seq-frame-01.png`) with a 4-row frame index. Distinct colors make a stepped
  frame visibly change. `seq-single.png` — a standalone image (no numbered
  siblings) that must NOT show the stepper. Generated by a stdlib-only Go program
  (`image/png`); regenerate with the snippet in `sequence-viewer.spec.ts`'s
  header comment if ever lost.
